# SAMS

## Quale skill usare

- Nuova feature / modifica di comportamento → `superpowers:brainstorming`, poi `superpowers:writing-plans`.
- `grilling` e `domain-modeling` NON si avviano da sole: si usano solo dentro `/grill-with-docs`.
- Vocabolario: se esiste `GLOSSARY.md`, leggilo prima di nominare file, funzioni o variabili e usa quei termini.
- TDD, debug e code review → solo le skill `superpowers:*`.
- `/handoff` salva il documento in `%TEMP%` (fuori dalla repo): spostalo nel vault Obsidian se va tenuto.

Le skill in `.claude/skills/` vengono da mattpocock/skills (versione in `.claude/skills/MATTPOCOCK_VERSION.txt`); la guida è nella nota Obsidian «Skill di Matt Pocock - guida».
